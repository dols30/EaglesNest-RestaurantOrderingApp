# Portfolio images

Screenshots of the actual running native Mac Catalyst app:

| Image | Dimensions | Use |
|---|---|---|
| `homepage.png` | 1200×840 | Main portfolio image |
| `homepage-large.png` | 1920×1080 | Large-window layout |
| `homepage-narrow.png` | 390×800 | Narrow-window reflow |

The narrow image captures the visible viewport; the rest of the welcome page scrolls. Images are not stretched to simulate different display sizes.

Food photography is AI-generated, illustrative, and bundled in the app. It does not depict food from an actual restaurant. The application is a local ordering demo; it does not collect payments or send orders to a kitchen.
